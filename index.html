39c1c9a wtwlt hyperlocal weather station · edge sensors + forecast go ›
ESP32 Go MQTT SQLite IoT

A self-hosted, hyperlocal weather station. A solar-powered ESP32 sensor node samples temperature, humidity, pressure, wind, rain, UV and lightning, then publishes over MQTT to a Raspberry Pi. A single Go service ingests the readings into SQLite and serves an earth-toned dashboard whose palette shifts with the time of day — overlaying a keyless forecast (Open-Meteo / NWS) on every chart.
